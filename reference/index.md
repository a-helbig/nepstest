# Package index

## Reading PVs

- [`read_pv()`](https://a-helbig.github.io/nepstest/reference/read_pv.md)
  : Read a programming template (PV) from a docx file

## Filters (ef-tags)

- [`ef_test()`](https://a-helbig.github.io/nepstest/reference/ef_test.md)
  : Tests ef-tags (entry filters)

## Autocodings (ac-tags)

- [`ac_test()`](https://a-helbig.github.io/nepstest/reference/ac_test.md)
  : Test if a target variable equals a specified value or another
  variable's value

## Date ranges (ra-tags)

- [`date_test_complex()`](https://a-helbig.github.io/nepstest/reference/date_test_complex.md)
  : Tests date ranges (ra-tags) of event or episode dates

## Labels (vb- and we-tags)

- [`label_test()`](https://a-helbig.github.io/nepstest/reference/label_test.md)
  : Tests variable labels against the PV
- [`value_label_test()`](https://a-helbig.github.io/nepstest/reference/value_label_test.md)
  : Tests value labels against the PV

## Superseded

Tests for exit filters (af-tags) in older PVs. Use
[`ef_test()`](https://a-helbig.github.io/nepstest/reference/ef_test.md)
for PVs with entry filters.

- [`af_test_simple()`](https://a-helbig.github.io/nepstest/reference/af_test_simple.md)
  : Tests simple af-tags (superseded)
- [`af_test_complex()`](https://a-helbig.github.io/nepstest/reference/af_test_complex.md)
  : Tests complex af-tags (superseded)
